# AutoGrow5 Example Scripts

This directory contains example shell scripts that demonstrate how to run
AutoGrow5 with different configurations.

## Scripts

There are three main scripts in this directory:

1. `autogrow_test.sh`: Runs a standard AutoGrow5 genetic algorithm for molecular
   generation.
2. `deepfrag_test.sh`: Runs AutoGrow5 with the DeepFrag filter enabled. DeepFrag
   uses a deep learning model to guide the fragment-based growth of molecules.
3. `cleanup.sh`: A utility script to remove all output directories, log files,
   and temporary files generated by the other scripts.

## Prerequisites

Before running these scripts, ensure that AutoGrow5 and all its dependencies are
properly installed. You will also need to have a molecular docking program (like
Vina) and Open Babel installed on your system.

## Setup

Before executing the run scripts, you must update the paths to the external
software executables within `autogrow_test.sh` and `deepfrag_test.sh`.

Open each `.sh` file and modify the following variables to point to the correct
locations on your system:

```bash
obabel_path="/SOME/PATH/obabel"
docking_executable="/SOME/PATH/vina_1.2.6_mac_aarch64"
```

Replace these values with the absolute path to the respective executables.

## Usage

You can execute the scripts from the command line using `bash`.

### Standard AutoGrow Run

To perform a standard run without the DeepFrag filter, execute:

```bash
bash autogrow_test.sh
```

The results will be stored in a new directory named `autogrow_out`.

### AutoGrow with DeepFrag Run

To run AutoGrow with the DeepFrag filter, which may improve the quality of
generated molecules, execute:

```bash
bash deepfrag_test.sh
```

The results for this run will be saved in the `with_deepfrag_out` directory.
Note that this script sets `multithread_mode` to `serial` because DeepFrag may
require CUDA, which can conflict with multiprocessing.

### Cleaning Up

After you are finished, you can clean up all generated files and directories by
running:

```bash
bash cleanup.sh
```

This will remove `autogrow_out`, `with_deepfrag_out`, and other temporary files,
restoring the directory to its original state.
